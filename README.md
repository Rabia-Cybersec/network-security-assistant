# Network Security Assistant

A personal network security assistant that scans and monitors my network.
It will grow step by step: network scanning, traffic monitoring,
AI-based anomaly detection, then automated responses.

## What I've learned

- **IP address and ports:** an IP address identifies a machine on a network,
  while a port identifies the program or service targeted on that machine
  (80 = HTTP, 443 = HTTPS, 22 = SSH).
- **TCP vs UDP:** TCP is reliable and confirms delivery (web, email, SSH).
  UDP is faster but gives no guarantee (video calls, streaming, games).
